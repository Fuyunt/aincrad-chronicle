AINCRAD CHRONICLE / 無料・iPad用記録端末 試作

1. このフォルダをそのまま無料の静的Webホスティング（GitHub Pagesなど）に公開すると、iPad SafariでURLを開けます。
2. iPadの「GPT用の再開指示をコピー」で内容をコピーし、iPhoneのChatGPTに貼り付けます（Apple端末間のユニバーサルクリップボードが有効な場合）。
3. ChatGPTが物語と共に返す更新JSONを、iPadの「同期」へ貼り付けて反映します。
4. セーブはSafariのlocalStorageに保存。Safariのデータ消去・端末変更に備え、定期的に「セーブJSONを保存」してください。
